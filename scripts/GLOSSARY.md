# Glossário PT-BR — Limbus Company (O Médio)

Termos obrigatórios (consistência com a base comunitária):

- Sinner → **Pecador** (pl. Pecadores; fem. Pecadora)
- Fixer → **Mandatário** (fem. Mandatária; pl. Mandatários/Mandatárias)
- Executive Manager → **Gerente Executivo** (Dante é MASCULINO — sempre "o Gerente Executivo", "Gerente" masc.)
- Manager → **Gerente**
- Abnormality → **Anormalidade**
- Wing → **Ala**
- Nest → **Ninho**
- Golden Bough → **Ramo Dourado**
- Qliphoth Deterrence → **Dissuasão de Qliphoth**
- After Team → **Equipe Posterior**; Before Team → **Equipe Anterior**
- Red Gaze → **Olhar Vermelho**
- Smoke War → **Guerra da Fumaça**
- core (da Anormalidade) → **núcleo**
- Mirror Dungeon → **Masmorra Espelhada** (Mirror World → **Mundo Espelhado**) — padrão consolidadov6.51.0
- Grade X Fixer → **Mandatário(a) de Grau X**
- Distortion → **Distorção**
- Bloodfiend → **Sanguinário**; Bloodbag → **Saco de Sangue**; Kindred → **Aparentado**
- Encounter → **Encontro**; Clash → **Embate**; Stagger → **Atordoamento**
- Identity → **Identidade**; E.G.O → **E.G.O** (mantém)
- Enkephalin → **Enkephalin** (mantém)
- The Ring → **O Anel**; The Middle → **O Meio** (base comunitária (06/2026); era "O Médio"); The Thumb → **O Polegar**; The Index → **O Indicador**; The Pinky → **O Mindinho**
- Nursefather → **Padrinho** (fem. **Padrinha**; base comunitária (06/2026) aposentou "Pai-Babá"; títulos: Padrinho do Meio/Indicador/Anelar/Mindinho/Polegar); Hierarch → **Patriarca**
- House of Spiders → **O Lar das Aranhas** (base comunitária (06/2026); era "Casa das Aranhas")
- Corridor → **Corredor**; fathoms of ego → **profundezas do ego**
- Status: Burn→Queimadura, Bleed→Sangramento, Tremor→Tremor, Rupture→Ruptura, Sinking→Afundamento, Poise→Equilíbrio, Charge→Carga, Breath→[Breath] (manter colchetes de tokens)
- Tokens entre colchetes `[Combustion]`, `[Laceration]`, `[Burst]` etc. → **manter verbatim**
- Nomes próprios (Yuri, Hopkins, Tomah, Charon, Vergilius, Faust, Outis, Ryōshū, Heathcliff, etc.) → **manter**
- Corp. names (L Corp., G Corp., N Corp., etc.) → **manter**
- "Damn/dammit" → droga; profanidade forte (fuck/shit) → traduzir naturalmente (foda-se, merda, caralho conforme tom)

Regras:
- Preservar BOM (UTF-8), CRLF e indentação de 4 espaços ao salvar.
- NÃO traduzir campos `id`, `key`, `tag`.
- Traduzir `content`, `dlg`, `title`, `place`, e `teller` quando for cargo/descrição (ex.: "Grade 8 Fixer" → "Mandatária de Grau 8"); manter `teller` quando for nome próprio.
- Tom: PT-BR natural, registro coloquial nos diálogos, formal/arcaico para Don Quixote.
